PatentPincer · prior-art search

Describe your invention. Find out if it's already patented.

One sentence in. PatentPincer searches Google Patents and Scholar through SerpApi, pulls the actual claim text of the closest references, compares your invention element by element, and stamps a verdict: file it, narrow it, or walk away.

How it works

Reading this page in one glance

  • ProvenanceLIVE means a real SerpApi response backed the run. FIXTURE means the offline demo corpus did, and a FIXTURE run is never allowed to return CLEAR. UNAVAILABLE means no search succeeded, which is a refusal and not a clearance.
  • Activity logThe recorded event stream of the run, with its real millisecond timings, one line per SerpApi call, guardrail decision, and verdict rule.
  • SerpApi ledgerEvery call the run actually made, with the status it returned. Nothing is inferred.
  • Claim-element matrixYour invention split into claim elements, each matched against a numbered claim of a cited reference, with the excerpt that carried the match. On a LIVE run those claims come from SerpApi's Google Patents Details API; on a FIXTURE run they come from the offline demo corpus.
  • VerdictThe stamp, computed from the matrix: Clear to file, Needs review, Likely anticipated, or Search unavailable.
  • BriefThe exported, decision-ready artifact, byte for byte what the CLI printed. Copy or download it.
